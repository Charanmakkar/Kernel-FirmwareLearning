# Interview preparation

Start with [Questions only](Questions_Only.md), then use [Answers](Answers.md) to score and correct your explanation. [Question index](Question_Index.csv) supports filtering by track, topic, difficulty, round and tags. [Machine-readable bank](bank.json) preserves every field. [Source register](sources.json) records primary references and access dates.

There are 200 distinct questions, including 40 coding exercises, 30 dedicated debugging scenarios, and 10 system-design exercises. Ten RTOS entries also carry scenario tags. Do not count overlapping tags as additional questions.

For an oral practice session, choose two foundation questions, two role questions, one coding task, and one failure scenario. Attempt independently, use the answer key to identify gaps, then repeat with changed inputs. Record evidence in the assessment tracker.
