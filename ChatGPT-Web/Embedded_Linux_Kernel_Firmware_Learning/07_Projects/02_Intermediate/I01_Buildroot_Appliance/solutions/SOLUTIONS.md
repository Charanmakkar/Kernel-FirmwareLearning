# I01 Exercise solutions

After file sync but before rename, the old counter remains the committed record; the next run overwrites the temporary file under the lock. After rename, the new name is visible to the running OS, but without directory sync a subsequent physical power loss still needs filesystem-specific evaluation. Host process exits do not simulate storage cache loss. For corrupt state, stop the service, copy the damaged record and logs into an incident directory, validate an operator-selected backup, write a fresh versioned file with its check word, synchronize file and directory, and record the reset reason. Never treat any parse failure as a missing file. The automated tests deliberately expect corruption to remain unchanged.
