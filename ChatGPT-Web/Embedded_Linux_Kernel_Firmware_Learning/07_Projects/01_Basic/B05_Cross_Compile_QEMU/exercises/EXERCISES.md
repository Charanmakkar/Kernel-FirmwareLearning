# B05 Independent exercises

Prerequisite: build and explain the reference project. Allow 45 minutes without AI, followed by 20 minutes of tool-assisted checking. Keep your changes in a separate copy. Submit code or design notes, tests, and a short explanation.

1. Run the dynamic AArch64 binary with a deliberately wrong empty sysroot and explain the failure before changing source code.
2. Change the accumulator to unsigned 32-bit and identify a test that detects loss of numeric range.

Score 10 points: correctness 4, boundary tests 2, reasoning 2, and communication 2. Pass at 8 with no unchecked memory access, deadlock, or false validation claim. If unsuccessful, repeat the relevant module lab and explain the invariant before trying again.
